# PG-Finder / Quest Habit RPG Frontend

A gamified habit-tracking frontend inspired by Habitica + Bounty Tasker, built as a responsive RPG-like productivity dashboard.

## Run

Open `index.html` in a browser.

## Key updates

- Habits and To-Dos are split into separate tabs.
- Habit/To-Do creation uses top overlay modals opened with `+` buttons.
- Hero dashboard now uses **4 equipment boxes**: Helmet, Armor, Shield, and Pet.
- Completed To-Dos open in a separate searchable list view.
- Metadata fields are shown as visual chips (type, stat, frequency, progress, due date, tags).
- Added dedicated `Collection` button and collection modal with unlocked items gallery.
- Added direct **Add Custom Item** flow (inventory button + collection modal) with markdown image syntax parsing (`![]()`) or plain URL, slot category, and unlock cost.
- Improved progress summary readability by spacing values and labels.
